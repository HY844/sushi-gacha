# 🍣 寿司ガチャ (Sushi Gacha)

回転寿司店で**「次になにを食べよう？」**と迷った時に、運任せでメニューを決めることができるおみくじ形式のWEBアプリケーションです。

### 🎯 寿司ガチャとは？（利用イメージ）
回転寿司のテーブルで「次に食べる一皿」をおみくじのようにランダムに決めてくれるアプリです。

- **「いつも同じネタばかり頼んでしまう…」**
- **「サイドメニューやデザートを頼むタイミングに迷う…」**
- **「グループや家族でワイワイ盛り上がりながら食べたい！」**

そんな時にボタンを押すだけで、ドラムロール演出とともに次のメニューを提案してくれます。「好きな寿司一皿」が当たるスペシャル演出や、隠し機能など、食事の時間を少し楽しくする仕掛けが詰まっています。

## 💡 メニューデータ（JSON）の準備手順

本アプリでは、最新のメニュー情報に対応するために `menu/sushiro.json` などのデータファイルを使用します。店舗のメニュー更新に合わせて、**生成AIを活用して簡単にJSONデータを作成する手順**は以下の通りです。

### 1. 店舗の公式サイトからメニューテキストをコピペ
スシロー・くら寿司・はま寿司などの公式サイトのメニューページを開き、メニュー名が載っているテキスト範囲を選択してコピーします。

### 2. 生成AI（ChatGPT, Gemini, Claudeなど）に整形プロンプトを送信
生成AIのチャット画面に、以下の**プロンプト例**と**コピペしたテキスト**を貼り付けて実行します。

> **プロンプト例:**
> ```text
> 以下のテキストからメニュー名とカテゴリーを抽出し、指定のJSON配列フォーマットに変換してください。
> 
> 【カテゴリーの分類ルール】
> - 寿司（握り、軍艦、巻物など） -> "寿司"
> - 麺類、汁物、揚げ物、おつまみなど -> "サイドメニュー"
> - ケーキ、アイス、パフェなど -> "デザート"
> - アルコール、ソフトドリンクなど -> "ドリンク"
> 
> 【出力フォーマット】
> [
>   { "name": "メニュー名", "category": "カテゴリー名" }
> ]
> 
> 【抽出テキスト】
> （ここに公式サイトからコピペしたテキストを貼り付け）
> ```

### 3. 生成されたJSONを保存
AIが出力したコードブロックをコピーし、該当するファイル（例: `menu/sushiro.json`）として保存・上書きしてください。
