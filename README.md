# 🍣 寿司ガチャ (sushi-gacha)

回転寿司のメニューからランダムで今日食べるものを決めるWebアプリケーションです。

---

## 🛠 メニューデータ（menu.json）の更新手順（AI活用）

寿司チェーン等の公式サイトから新しいメニュー情報を取得し、`menu.json` を最新状態にアップデートする際の手順です。

### ステップ 1：生成AIにプロンプトとテキストを渡す

ChatGPT や Gemini 等を開き、以下の【送信テンプレート】と公式サイトからコピーしたメニューテキストをセットにして送信します。

#### 【送信テンプレート】

以下のURLに記載された抽出ルールとフォーマットに従って、下のテキストから JSON を作成してください。

URL: https://raw.githubusercontent.com/HY844/sushi-gacha/main/PROMPT.md

---【入力テキスト】---
(ここにスシロー等の公式サイトからコピーしたテキストを貼り付け)


---

### ステップ 2：menu.json ファイルの書き換え（アップデート）

1. **AIの出力をコピー**: 生成AIが出力した JSON コード（```json 〜 ``` の中身）をすべてコピーします。
2. **VS Code で上書き保存**: VS Code で **`menu.json`** を開き、コピーした新しい内容で全内容を上書き保存（`Ctrl` + `S`）します。

---

### ステップ 3：GitHub への反映

1. GitHub のリポジトリ画面（`sushi-gacha`）を開きます。
2. 画面右上付近にある **`+`（プラス）アイコン** をクリックし、**「Upload files」** を選択します。
3. アップデートした **`menu.json`** をドラッグ＆ドロップします。
4. 画面下の緑色ボタン **「Commit changes」** をクリックしてコミット（更新完了）します。
5. 1〜2分後、スマホ等でWebサイトを開いて再読み込みし、最新メニューが反映されているか確認します。

---

## 📁 主要ファイル構成

- **`index.html`** : 寿司ガチャのメイン画面・処理プログラム
- **`menu.json`** : ガチャで抽選されるメニューデータ（商品名・カテゴリー）
- **`PROMPT.md`** : 生成AIに `menu.json` を作成させるための指示文（プロンプト）
- **`README.md`** : 本プロジェクトの概要・運用マニュアル（このファイル）
